# 📌 Naukri Profile SOP — Data Science (XDSAAI)

**Placement Readiness Program **

---

## 🎯 Objective
This SOP ensures that every candidate creates a **100% optimized Naukri profile** aligned with recruiter search algorithms for **Data Science / ML roles**.

---

## ✅ SECTION 3A — NAUKRI PROFILE CHECKLIST (MANDATORY)

### 👤 Basic Profile Setup
- Profile Completeness → **100% (Mandatory)**
- Profile Designation → *Data Science Engineer / Data Analyst / ML Engineer*
- Location → **Pune**
- Notice Period → **15 days or less**
- Employment Type → **Full-Time (Compulsory)**

---

### 🔐 Verification
- Profile Photo → **Verified**
- Mobile Number → **Verified**
- Email ID → **Verified**

---

### 📄 Resume & Headline
- Updated **Data Science Resume** must be uploaded
- Resume Headline must include **DS/ML keywords**

**Example:**
Data Science Engineer | Python | Machine Learning | SQL | NLP | Tableau | Power BI


---

### 🧠 Key Skills (Mandatory Keywords)
Python, Machine Learning, SQL, Tableau, Power BI,
NLP, Deep Learning, Pandas, Scikit-learn, TensorFlow, MLOps


---

### 💼 Employment Details
- Add Internship:
  - *Analytix Solutions / Relevant DS Company*
  - Duration: **Max 9 months**

---

### 🌍 Preferences
- Preferred Shift → **Flexible (NOT Day Shift)**
- Preferred Locations → **Add all 10 locations**
- Expected Salary → ❌ **DO NOT ADD**

---

### 🏢 Industry & Role Setup
- Current Industry → *IT Services / Analytics*
- Department → *Data Science & Analytics*
- Role Category → *Data Science & Analytics*
- Job Role → *Data Science Engineer / Data Analyst*

---

### 💻 IT Skills Section
- Add **10 IT Skills (Mandatory)**
- Ensure:
  - All durations are **consistent**
  - Skills match your resume

---

### 🌐 Languages
- Add all known languages
- Mark proficiency as **Expert**

---

### ✍️ Profile Summary (IMPORTANT)
- Use **all 4,000 characters**
- Include:
  - Skills
  - Tools
  - Internship work
  - ML/NLP keywords

---

### 🎓 Education (Naukri Optimization)
- Use:
  - **BSc / BTech / BE — Computer / Statistics**
- Follow:
  - **Reverse chronological order**

---

### 💰 Salary Guidelines
- Experienced → **Below 6 LPA**
- Intern/Fresher → **Below 2 LPA**

---

## 🚫 SECTION 3B — DO's & DON'Ts

### ✅ DO's
- ✔ Profile must be **100% complete**
- ✔ Add **DS/ML keywords** in Resume Headline
- ✔ Fill **all 4,000 characters**
- ✔ Add **top 5 skills**:
  - Python, ML, SQL, Tableau, Deep Learning
- ✔ Interns → Select **Full-Time**
- ✔ Fill **all fields completely**
- ✔ Add **all DS tools (even basic knowledge)**
- ✔ Education → **Reverse order**
- ✔ Use **Computer / Statistics stream** (for better ranking)

---

### ❌ DON'Ts
- ✗ Avoid phrases like **"I can", "I will"**
- ✗ Do NOT explain technologies
- ✗ Do NOT mention **client names**
- ✗ Do NOT add **non-DS projects**
- ✗ Do NOT divide responsibilities tool-wise
- ✗ No duplication of content
- ✗ Do NOT use **AI-generated generic content**
- ✗ Do NOT add **Expected Salary**
- ✗ Do NOT select **Day Shift** (use Flexible)

---

## 🚀 Final Checklist Before Applying
- [ ] Profile 100% complete  
- [ ] Resume updated  
- [ ] Keywords added  
- [ ] Internship added  
- [ ] 10 IT skills completed  
- [ ] 4000-character summary filled  
- [ ] Preferred locations added  
- [ ] Salary field empty  

---

## 📌 Important Note
> This SOP is mandatory for placement eligibility.  
> Profiles not meeting these standards may face **low recruiter visibility**.
